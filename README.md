# kras-g12d-pmhc-comp5
Design against the whole peptide-MHC complex: the HLA-A*11:01 heavy chain, β2-microglobulin and a ten-residue peptide held in the groove. This challenge asks for three things: bind the G12D complex, do not bind the wild-type one, and do not bind the same HLA with no peptide in it.
